# 決定の記録（ADR）

このリポジトリだけに関わる決定を置く。決着済みの事項は蒸し返さない。議論を再開する場合は、ADR を読んでから差分だけを扱う。

- **0001〜0007 は着手の条件**（[docs/kickoff.md](../kickoff.md)）。最初に必ず決める。状態を「採用」にするまで実装に入らない
- 新しい ADR は `0000-template.md` を写し、`NNNN-題.md` にする。番号は通し番号（0008 から）。0017 は横断の記録から持ってきた番号のまま残す
- 状態：提案 → 採用 → 撤回／置き換え（→ NNNN）。覆す条件が書けないものは「提案」のまま
- 人の判断が要る論点は、先に Issue（テンプレート「決めてほしいこと」）で出す
- 複数のリポジトリにまたがる決定は、ここではなく横断の記録（working-out-loud の `docs/decisions/`）に置き、ここからは番号で参照する
