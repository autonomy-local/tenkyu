## 背景

Tenkyu は OSS として公開すると決めている。README も LICENSE も Apache-2.0 だが、貢献の条件と第三者のコードの扱いを文書にしていない。

## 決めたこと

| 項目 | 決めたこと |
| --- | --- |
| 配布 | Apache-2.0（`LICENSE`） |
| 著作権 | 合同会社オートノミーアソシエーション |
| 外部からの貢献 | 今は PR を受け付けない。不具合の報告（Issue）は歓迎する（README） |
| 第三者のコード | 移植したものは PR の「移植か、新規か」に元のファイルとライセンスを書く |

**未決**：`NOTICE` を置くこと（README が参照しているがファイルがない）。PR を受け付けるときの条件（DCO か CLA か）は、受け付けると決めるまで先送りする。

## 理由

公開する部分と非公開の部分の境目を配備の単位で分けているので、基盤は広く使える Apache-2.0 が合う（ADR 0017）。

## 検討した他の案

- FSL、PolyForm：OSS の基盤として使ってもらう目的に合わないので採らない

## 覆す条件

- 外部からの貢献を受け付けると決めたとき：貢献の条件を決める
