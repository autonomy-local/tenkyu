# PRD（プロダクト要求）

「何を、誰のために、なぜ作るか」と「どうなったら成功か」を書く。「どう作るか」は ADR に書く。

- `0001-プロダクト.md`：プロダクト全体の PRD。**着手の条件**（[docs/kickoff.md](../kickoff.md)）の1つ。状態を「承認」にするまで実装に入らない
- 機能ごとの PRD は `0000-template.md` を写し、`NNNN-題.md` にする。番号は通し番号
- 状態：下書き → 承認 → 改訂（YYYY-MM-DD）。改訂したら、変えた節と理由を末尾に足す
